About Image Processing Lab

This web application is an interactive Image Processing Lab built using Python, OpenCV and Flask for the college Image Processing Subject (5th Semester). It provides interactive, verified implementations of all 11 curriculum practicals with actual image processing computations.

Key Technical Highlights:

  • 100% Real OpenCV Processing: Every uploaded or camera-captured image is decoded into a NumPy matrix and processed using native OpenCV (cv2) algorithms. No fake or pre-rendered outputs.
  • Live Camera Capture: Native browser camera capture using the MediaDevices API, enabling direct photo capture for instant processing across all 11 practicals.
  • One-Click Direct Download: High-resolution processed images are instantly downloadable with semantic naming conventions.
  • Interactive Damage Masking: Practical 6 features an HTML5 canvas brush allowing students to draw scratches and mark defect regions in real-time.
  • Real Byte Compression Analysis: Practical 7 calculates actual compression savings and ratios dynamically.

Curriculum Coverage:

P1: Basics & Bitwise Arithmetic
P2: Geometric Transformations
P3: Image Enhancement
P4: Spatial Domain Enhancement
P5: Spatial Filters
P6: Image Inpainting
P7: Image Compression
P8: Morphological Operations
P9: Object Detection (Haar)
P10: Edge Detection (Canny)
P11: Colour Spaces (HSV, LAB, etc.)
